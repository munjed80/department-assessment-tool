# أداة دراسة الأقسام والتحول الرقمي

تطبيق عربي بسيط يعمل بالكامل دون إنترنت من ملف واحد فقط: `index.html`.

## طريقة التشغيل

1. حمّل ملف ZIP الخاص بالمشروع.
2. فك ضغط الملف في أي مجلد على جهازك.
3. افتح الملف `index.html` مباشرة بالنقر المزدوج.
4. استخدم أحد المتصفحات التالية: Chrome أو Edge أو Firefox.
5. لا تحتاج إلى تثبيت npm أو Node.js.
6. لا تحتاج إلى تشغيل `npm install`.
7. لا تحتاج إلى تشغيل `npm run dev`.
8. لا يوجد Vite أو React أو خادم أو قاعدة بيانات خارجية.

## العمل دون إنترنت

التطبيق يعمل دون إنترنت بعد فتح ملف `index.html`، ولا يحتاج إلى اتصال بالشبكة أثناء الاستخدام العادي.

## حفظ البيانات

- يتم حفظ البيانات محليا داخل المتصفح باستخدام `localStorage`.
- لا تستخدم وضع التصفح الخاص أو الخفي، لأن المتصفح قد يحذف البيانات بعد إغلاق النافذة.
- لا تمسح بيانات المتصفح أو ملفات الموقع، لأن ذلك قد يؤدي إلى حذف بيانات التطبيق.
- يفضّل استخدام نفس المتصفح ونفس الجهاز عند متابعة العمل.

## النسخ الاحتياطي الضروري

يجب تصدير نسخة احتياطية JSON بعد كل يوم عمل من تبويب **النسخ الاحتياطي**.

خطوات النسخ الاحتياطي:

1. افتح تبويب **النسخ الاحتياطي**.
2. اضغط **تصدير نسخة احتياطية**.
3. احتفظ بملف JSON في مكان آمن.

لاستعادة نسخة احتياطية:

1. افتح تبويب **النسخ الاحتياطي**.
2. اضغط **استيراد نسخة احتياطية**.
3. اختر ملف JSON السابق.
4. وافق على استبدال البيانات الحالية إذا كنت متأكدا.

## التقارير وحفظ PDF

لحفظ أي تقرير بصيغة PDF:

1. افتح تبويب **التقارير**.
2. اختر نوع التقرير المطلوب.
3. اضغط **عرض التقرير**.
4. اضغط **طباعة التقرير**.
5. من نافذة الطباعة في المتصفح اختر **Save as PDF** أو **حفظ كملف PDF**.

## الوظائف الأساسية

- إضافة وتعديل وحذف الأقسام.
- إضافة وتعديل وحذف المقابلات.
- إضافة وتعديل وحذف المشاكل.
- حساب درجة الأولوية تلقائيا حسب المعادلة:

```text
درجة الأولوية = درجة الشدة × درجة التكرار × درجة الاستعجال
```

- تصدير الأقسام بصيغة CSV.
- تصدير المقابلات بصيغة CSV.
- تصدير المشاكل بصيغة CSV.
- تصدير واستيراد نسخة احتياطية JSON.
- طباعة التقارير وحفظها كملف PDF من المتصفح.

## ملاحظة مهمة

البيانات محفوظة محليا داخل هذا المتصفح فقط. إذا تم حذف بيانات المتصفح أو استخدام جهاز آخر دون استيراد نسخة احتياطية، فلن تظهر البيانات السابقة.
