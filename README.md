# Department Assessment Tool

أداة داخلية خفيفة جدًا لتقييم الإدارات أثناء المقابلات الميدانية. التطبيق يعمل كواجهة فقط داخل المتصفح، ولا يحتاج إلى خادم، قاعدة بيانات، Docker، تسجيل دخول، أو اتصال إنترنت أثناء الاستخدام اليومي.

## ما الذي يفعله التطبيق؟

- واجهة عربية RTL.
- صفحات رئيسية ثابتة:
  - لوحة التحكم
  - الإدارات
  - المقابلات
  - المشكلات
  - التقارير
- إضافة وتعديل وحذف الإدارات.
- إضافة وتعديل وحذف المقابلات.
- إضافة وتعديل وحذف المشكلات.
- توثيق سير العمل الحالي، الروتينات، المشكلات، الأسباب الجذرية، الحلول المقترحة، والملاحظات.
- حساب أولوية المشكلة تلقائيًا:

```text
priority_score = severity_score * frequency_score * urgency_score
```

- تصدير كل البيانات كنسخة احتياطية JSON.
- استيراد نسخة احتياطية JSON.
- تصدير المشكلات CSV.
- تصدير المقابلات CSV.
- صفحة تقرير قابلة للطباعة للإدارة.

## أين يتم حفظ البيانات؟

كل البيانات تحفظ محليًا في المتصفح باستخدام `localStorage` على نفس جهازك ونفس المتصفح.

مهم:

- لا توجد قاعدة بيانات خارجية.
- لا يوجد خادم Backend.
- لا يوجد رفع للبيانات إلى الإنترنت.
- إذا غيرت المتصفح أو مسحت بيانات المتصفح فقد تفقد البيانات، لذلك صدّر نسخة JSON احتياطية بشكل دوري.

## التشغيل البسيط أثناء ضعف الإنترنت

تحتاج الإنترنت مرة واحدة فقط لتنزيل حزم الواجهة عند أول إعداد. بعد ذلك يمكنك تشغيل التطبيق محليًا بدون إنترنت.

```bash
cd client
npm install
npm run dev
```

ثم افتح الرابط الذي يظهر في الطرفية، غالبًا:

```text
http://localhost:5173
```

## بناء نسخة ثابتة محلية

إذا أردت تجهيز نسخة ثابتة داخل مجلد `client/dist`:

```bash
cd client
npm install
npm run build
```

بعد البناء يمكنك تجربة النسخة الثابتة محليًا عبر:

```bash
npm run preview
```

أو فتح ملف `client/dist/index.html` مباشرة من المتصفح. إذا منع المتصفح فتح ملفات JavaScript المحلية من `file://`، استخدم أمر `npm run preview` بدلًا من الفتح المباشر.

## النسخ الاحتياطي والاسترجاع

من داخل التطبيق:

1. اضغط **تصدير نسخة JSON** لحفظ كل البيانات في ملف احتياطي.
2. احتفظ بالملف في مكان آمن مثل مجلد المشروع أو USB.
3. عند الحاجة، اضغط **استيراد JSON** واختر ملف النسخة الاحتياطية.

## ملاحظات للاستخدام الميداني

- قبل الذهاب للمقابلات، شغل التطبيق مرة وتأكد أن الصفحة تفتح.
- صدّر نسخة JSON بعد كل يوم مقابلات.
- لا تحتاج إلى تشغيل أي شيء داخل مجلد `server`؛ تم حذف الخادم وقاعدة SQLite من المشروع.
